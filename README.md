# xvexi

轻之国度第三方阅读客户端（Android）——安静、克制、书卷感的开源轻小说阅读器。

## 📥 下载

- **[最新 Release](../../releases)** —— APK 直接下载（GitHub CDN，海量下载无压力）
- [在线下载页](https://lnreader-apk.app.workbuddy.host/?sharecode=UQF2DZDO4O) —— 含安装步骤与校验值

## ✨ 功能

- **书架**：封面主视觉网格，阅读进度同步
- **首页**：排行榜 / 猜你喜欢（按常看标签推荐）/ 最近更新 / 题材板块
- **分类浏览**：热度 / 最新 / 评分 / 字数 / 评价数排序，大图标 ↔ 列表切换，无限加载
- **阅读器**：翻页动画、主题模式 / 配色自选 / OLED 纯黑、字号行高调节
- **实用**：网络连接诊断、错误日志一键复制、应用内检查更新、清理缓存

## 📦 安装

1. 下载 `xvexi-x.y.z-release.apk`
2. 系统提示「未知来源应用」时选「允许来自此来源」
3. 覆盖安装不丢书架与阅读进度

## 🔒 校验
